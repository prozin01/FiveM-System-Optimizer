# Changelog - FiveM System Optimizer

## [2.1.0] - 2024-10-15

### ✨ Features
- ✅ Otimização completa de mouse (raw input, polling rate)
- ✅ Otimização de teclado (response time máximo)
- ✅ Configuração automática de Power Plan
- ✅ Desabilitação de Game Bar e Game DVR
- ✅ CPU configurado para 100% de desempenho
- ✅ GPU priority elevation
- ✅ USB power saving desabilitado
- ✅ Timer configurado para 0.5ms (HPET OFF)
- ✅ Remoção de serviços desnecessários
- ✅ Interface de linha de comando amigável

### 🐛 Bug Fixes
- Corrigido problema de elevação de privilégio
- Melhorada compatibilidade com Windows 11
